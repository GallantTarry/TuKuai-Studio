KuaiBlog

A zero-bundler Docsify Markdown blog & knowledge-base engine distributed as an npm CLI. Turn any folder of .md articles into a polished static site with Geek Dark & Pastel Light dual themes, IDE-grade syntax highlighting, MathJax LaTeX, Mermaid 12 diagrams, native audio/video players, and SHA-256 search cache invalidation.

Theme Engine
Dual Themes & Long-Press

Click the bottom-right floating dot to toggle the sidebar; long-press for 500ms to switch between Geek Dark (Emerald) and Pastel Light (Aurora).

Search Sync
SHA-256 Cache Busting

Automatically hashes all Markdown content into js/search-version.js to purge stale browser localStorage indexes on updates.

Syndication
Git-Aware RSS 2.0 Feed

Extracts H1 titles, first-commit timestamps via git log, and plain-text summaries into feed.xml while skipping locked directories.

Visualization
Offline Diagram & Math Stack

Ships local Mermaid 12.2.0, MathJax SVG, Chart.js, D3.js v7, and Spectral.js—plus automatic cleanup for double-escaped AI LaTeX formulas.

Code & Gallery
IDE Prism & Viewer.js

Subdivides Prism keywords into data types and control flow colors, wraps wide tables for mobile, and attaches Viewer.js lightbox zoom to images.

Access Control
Private Folder Gate & CRT

Includes an optional session-based client-side password gate for private sections and a nostalgic CRT turn-off animation on header click.

        Windows One-Click Sidebar Refresh
        refresh_sidebar.bat
    

    

        Skip typing terminal commands on Windows. Double-click a .bat batch file in your blog root (already generated by npx kuaiblog init) to rebuild _sidebar.md, js/search-version.js, and feed.xml instantly.

            Path Resolution Rule (media/... vs ../../media/...):

            Custom HTML elements (<tukuai-player> and <tukuai-audio>) resolve url and cover relative to the root index.html, so always start directly with media/videos/XXX.mp4 or media/music/XXX.mp3.

            Standard Markdown images (![alt](...)) are resolved by Docsify relative to the current .md file's subfolder depth: use ../../media/XXX.jpg for two-level nested posts (e.g., posts/category/article.md) or ../media/XXX.jpg for single-level posts (posts/article.md).
